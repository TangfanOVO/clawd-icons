# Clawd 动态版

111 个功能与备选，每个都有专属动作、眨眼、开心、待机与睡着状态。

![身体与物件的互动](../preview/interactions.gif)

请将 `svg/` 中需要的 SVG **内联**到页面，引入 `clawd-motion.css`、`clawd-motion.js`，再调用 `ClawdMotion.play(element)`。仅通过 `<img>` 或外部雪碧图 `<use>` 引用时是静态图形。
